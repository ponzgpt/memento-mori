# Production Readiness

Memento Mori is ready to publish as a source-installable release: the Linux Waybar module, local desktop component app, source installers, documentation, checksums, and release gates are all versioned and auditable.

It is not yet a signed native-installer release for macOS or Windows, and it is not yet an App Store/TestFlight iOS release. That distinction matters. A death clock should not need marketing fog.

## Current Release State

## Required Gate

```sh
npm run verify
```

The gate covers audit, production-readiness checks, installer checks, release-readiness checks, web smoke checks, lint, tests, release notes, packaging, Python compile, Waybar smoke, whitespace checks, artifact checksums, and release manifest consistency.

## Shipping Rule

Use these labels in release notes and sales pages:

- Linux: ready as a source-installable Waybar-compatible module.
- macOS: source-installable until Developer ID signing, notarization, stapling, and clean-account install QA are complete.
- Windows 11: source-installable until Authenticode signing, SmartScreen caveat, and clean-account install QA are complete.
- iOS: documented direction until SwiftUI/WidgetKit source and TestFlight or App Store distribution exist.

Paid downloads may sell convenience packaging. They must not imply support entitlement, clinical accuracy, actuarial certainty, insurance suitability, or hidden functionality.

## Acknowledgments

The product borrows from memento mori and vanitas traditions: Stoic reflection, classical still-life symbols, Christian and post-Christian death imagery, hourglasses, bones, skulls, candles, ash, and the useful discomfort of a visible deadline.
