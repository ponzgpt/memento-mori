# Support

Memento Mori is provided as-is.

There is no support entitlement for source users or paid convenience-installer users. Issues and pull requests are welcome when they improve the project, but response times are not promised.

Good issue reports include:

- OS and version.
- Install path used: source or release artifact.
- Bar/shell used, for example Waybar, macOS menu bar, or Windows tray.
- Screenshot of the widget state when relevant.
- Terminal output from the smoke test.

Do not include private medical details, diagnoses, documents, or personal health history. The model is approximate and reflective only.

Privacy boundaries and local profile paths are documented in [PRIVACY.md](PRIVACY.md).
